# Layer

> This class extends [Displayble](./displayable)

You can manage the layers of the displayables by using the `Layer` class.

## Usage

```typescript
import {Layer} from "narraleaf-react";
```

```typescript
const layer = new Layer("layer name", {
    zIndex: 1
});

const scene = new Scene("scene with layers", {
    layers: [layer] // register the layer to the scene
});

const image = new Image({ /* ... */}).useLayer(layer); // link the image to the layer
```

```typescript
layer.opacity(0.5, 1000, "linear"); // change the opacity of the layer, all elements linked to the layer will be affected
```

## Chainable Methods

### setZIndex

<Steps>

Set the z-index of the layer. Higher z-index means the layer will be on top of the other layers.

- `zIndex: number` - The z-index of the layer

</Steps>

This is how depth **between** layers is controlled, and the comparison is applied before the order of elements inside any one layer. To reorder elements that share a layer, use [`Displayable.bringToFront`](./displayable#bringtofront).

## Public Methods

### constructor

<Steps>

- `name?: string` - The name of the layer
- `config?: Partial<ILayerUserConfig>` - The configuration of the layer, see [ILayerUserConfig](../types/ILayerUserConfig)

</Steps>

### include

<Steps>

Include the displayable to the layer.

- `elements: (Image | Text)[] | Image | Text` - The displayable to include, ex. [Image](./image), [Text](./text)
- Returns `this`

</Steps>

### bringToFront

<Steps>

Not available on a layer. `Layer` inherits this method from [Displayable](./displayable), but calling it throws a `RuntimeGameError` while the story is being built.

A layer is not an entry in another layer's list of elements, so it has no front to be moved to. Use [`setZIndex`](#setzindex) to raise a layer instead.

```typescript
layer.setZIndex(10);   // this is how a layer moves forward
layer.bringToFront();  // RuntimeGameError
```

</Steps>
