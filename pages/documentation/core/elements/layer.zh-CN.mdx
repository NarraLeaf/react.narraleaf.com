# 图层

> 此类继承自 [Displayble](./displayable)

你可以使用 `Layer` 类来管理可显示元素的图层。

## 用法

```typescript
import {Layer} from "narraleaf-react";
```

```typescript
const layer = new Layer("图层名称", {
    zIndex: 1
});

const scene = new Scene("带有图层的场景", {
    layers: [layer] // 将图层注册到场景中
});

const image = new Image({ /* ... */}).useLayer(layer); // 将图像链接到图层
```

```typescript
layer.opacity(0.5, 1000, "linear"); // 更改图层的不透明度，所有链接到图层的元素都会受到影响
```

## 链式方法

### setZIndex

<Steps>

设置图层的 z-index。z-index 越高，图层越靠前。

- `zIndex: number` - 图层的 z-index

</Steps>

图层**之间**的前后关系由此控制，并且这一层比较先于任一图层内部元素的顺序生效。若要调整同一图层内元素的顺序，请使用 [`Displayable.bringToFront`](./displayable#bringtofront)。

## 公共方法

### constructor

<Steps>

- `name?: string` - 图层的名称
- `config?: Partial<ILayerUserConfig>` - 图层的配置，参见 [ILayerUserConfig](../types/ILayerUserConfig)

</Steps>

### include

<Steps>

将可显示元素包含到图层中

- `elements: (Image | Text)[] | Image | Text` - T要包含的可显示元素，例如 [Image](./image), [Text](./text)
- 返回 `this`

</Steps>

### bringToFront

<Steps>

图层不支持该方法。`Layer` 从 [Displayable](./displayable) 继承了它，但调用时会在故事构建阶段抛出 `RuntimeGameError`。

图层并不是另一个图层元素列表中的条目，因此不存在可以被提到的最前位置。若要让图层前移，请改用 [`setZIndex`](#setzindex)。

```typescript
layer.setZIndex(10);   // 让图层前移的正确做法
layer.bringToFront();  // RuntimeGameError
```

</Steps>
